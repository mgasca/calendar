# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately via
[GitHub private vulnerability reporting](https://github.com/mgasca/calendar/security/advisories/new).

You can expect an acknowledgement within a few days. Once a fix is available, the advisory will be published with credit to the reporter (unless you prefer otherwise).

## Supported versions

Only the latest commit on `main` is supported.
