The report names the critical path of a run (which jobs, and its median), and reports the latency lens (critical path, and queue time or a statement that it was not sampled) separately from the compute lens (job time per run). When it discusses a job that is not on the critical path, it says that shortening that job frees compute but does not shorten the wait.
