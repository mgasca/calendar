Calendar container image

Type: container

One image built by the multi-stage Dockerfile: the pnpm build of the SPA is copied into the API’s wwwroot and published with the .NET 10 runtime image, running as a non-root user on port 8080. The same SHA-tagged image is promoted from staging to production (ADR-0030, ADR-0034).
